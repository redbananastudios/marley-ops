## Summary

The blind-sweep guard worked exactly as designed — the run failed loudly (HTTP 500, `ok:false`) instead of green-painting `settled:0` — but the underlying Zoho read path is broken and payments recorded in Zoho will not be detected until it recovers.

Actual: HTTP 500 `{"ok":false,"error":"every ledger status read failed (9/9) — this run reported no change because it could not CHECK anything, not because nothing changed","checked":7,"settled":0,"statusReads":9,"unreadable":9}`.
