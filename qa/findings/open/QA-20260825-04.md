## Summary
The "Add a line" bottom sheet's Description and Amount (£) text inputs have no accessible name — a screen reader announces them as unlabelled edit fields, not "Description" / "Amount (£)".

## Repro
1. Role: estimator (marker login). URL: `/estimator/pay/<any draft statement id>`.
2. Click "Add a line".
3. Inspect the two `<input>` elements in the sheet (`components/estimator/estimator-statement-editor.tsx`'s `LineSheet`).
4. Expected: each input exposes an accessible name matching its visible `<label>` text ("Description", "Amount (£)"), e.g. via `htmlFor`/`id` or `aria-label`.
5. Actual: neither input has an `id`, `aria-label`, or `aria-labelledby`, and the `<label>` elements are plain siblings with no `htmlFor` — confirmed live via `page.evaluate()` DOM inspection (all four fields null/false) and independently via Playwright's `getByLabel("Description")`, which times out finding no match at all.

## Evidence
Live DOM diagnostic on `/estimator/pay/<statement>` after opening "Add a line":
```json
[
  { "placeholder": "e.g. Agreed adjustment", "id": null, "ariaLabel": null, "ariaLabelledby": null, "hasWrappingLabel": false },
  { "placeholder": "50", "id": null, "ariaLabel": null, "ariaLabelledby": null, "hasWrappingLabel": false }
]
```
`page.getByLabel("Description")` — 30s timeout, 0 matches, forcing the workaround of locating by placeholder instead.

## Suspected cause
`components/estimator/estimator-statement-editor.tsx` lines ~341–358 (`LineSheet`): `<label className="...">Description</label>` immediately followed by an `<input>` with no `id`/`htmlFor` link and no `aria-label`; same pattern for the Amount field. The crew equivalent, `components/my-jobs/statement-editor.tsx` (`LineSheet`, ~line 353 onward — Description/Hours/Rate/Date), has the identical unlinked-label shape and likely wants the same fix.

## Verify
On `/estimator/pay/<draft statement>`, open "Add a line" and confirm `page.getByLabel("Description")` and `page.getByLabel("Amount (£)")` (or `getByLabel(/Amount/)`) each resolve to exactly one input. Bonus: same check against `/my-jobs/pay`'s "Add a line" sheet for Description/Hours/Rate/Date.
